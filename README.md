# Windows-Terminal-But-Beauty

This repository contains my Windows Terminal configuration files. I keep them here as a backup so I can quickly restore my setup after reinstalling or formatting my system. If you like the look of my terminal, feel free to use or adapt these files for your own setup.

I'm also including two videos that helped me a lot while customizing my terminal. If you're planning to personalize yours, I highly recommend checking them out:

- https://youtu.be/z3NpVq-y6jU?si=4vbCFvpFXHilSsn1
- https://youtu.be/-G6GbXGo4wo?si=AxLnHCkG1yvgRRoi

A huge thank you to the creators of these videos for sharing such clear and helpful guides. Their work made the entire customization process much easier.

This configuration uses **Nerd Fonts** to display icons correctly. You can download them from the official repository:

https://github.com/ryanoasis/nerd-fonts

Many thanks to the Nerd Fonts project and all of its contributors for creating and maintaining such an amazing collection of patched fonts.
